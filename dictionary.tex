\section{Current Status (Evidence-Based)}
% ============================================================================

\subsection{Summary of Findings}

The provided ZIP artifacts contain multiple \emph{processed} modeling-ready CSV extracts and supporting metadata. However, they \textbf{do not contain}:
\begin{enumerate}
    \item The underlying ENA raw CSV modules
    \item The transformation code (scripts/notebooks) that builds the final datasets
\end{enumerate}

This limits full traceability of variable construction and prevents end-to-end reproducibility from raw data.

\subsection{ZIP Archive Contents}

\subsubsection{Archive.zip}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Intermediate metadata:}
    \begin{itemize}
        \item \texttt{ena2024\_dictionary.csv} --- Variable codes with Spanish descriptions
        \item \texttt{variable\_map.json} --- Raw to cleaned feature name mapping
        \item \texttt{module\_profile.csv} --- ENA module file inventory
        \item \texttt{raw\_manifest.csv} --- Raw file manifest
        \item Various \texttt{*.parquet} intermediate files
    \end{itemize}
    \item \textbf{Processed outputs:}
    \begin{itemize}
        \item Multiple \texttt{model\_data\_ena2024*.csv} files
        \item Treatment effect outputs: \texttt{ena2024\_with\_TE*.csv}
    \end{itemize}
\end{itemize}

\subsubsection{processed.zip}
District-level external features in \texttt{data/external/processed/}:
\begin{itemize}[leftmargin=1.5em]
    \item CHIRPS precipitation data (parquet + JSON metadata)
    \item Temperature aggregates
    \item Topography features (elevation, slope, ruggedness)
    \item UBIGEO district capital coordinates
\end{itemize}

Contains only a placeholder (\texttt{.DS\_Store}). \textbf{No ENA raw data modules are present.}

\subsection{Inferred Data Pipeline}
% ============================================================================

Based on file names and column structures, the current pipeline appears to follow these steps:

\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{Raw data ingestion:} Start from ENA 2024 survey microdata (CSV modules listed in \texttt{module\_profile.csv})
    
    \item \textbf{Feature construction:} Aggregate UA-level outcomes and features (farm size, crop diversification indices, labor totals, cost totals)
    
    \item \textbf{Control variables:} Build controls from ENA modules (irrigation, mechanization, seed type, training, credit, association membership) with missingness flags
    
    \item \textbf{Geospatial merge:} Join district-level covariates via 6-digit UBIGEO:
    \begin{itemize}
        \item CHIRPS precipitation (with baseline statistics)
        \item Temperature aggregates (2023--2024)
        \item Topography (elevation, slope, ruggedness)
        \item District capital coordinates and area
    \end{itemize}
    
    \item \textbf{Export:} Generate modeling datasets under \texttt{processed/model\_data\_ena2024*.csv}
    
    \item \textbf{Treatment effects:} Produce TE outputs under \texttt{processed/ena2024\_with\_TE*.csv}
\end{enumerate}

\textbf{Merge key for TE files:} \texttt{anio, ccdd, ccpp, ccdi, psu, id\_prod, ua}

\subsection{Reproducibility Gaps and Recommended Fixes}
% ============================================================================

\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{Raw ENA modules missing}
    \begin{itemize}
        \item \textit{Issue:} Module inventory exists but referenced raw CSVs are absent
        \item \textit{Fix:} Add raw modules or documented data-access step with checksum manifest
    \end{itemize}
    
    \item \textbf{Transformation code missing}
    \begin{itemize}
        \item \textit{Issue:} No \texttt{.py}, \texttt{.R}, \texttt{.do}, or \texttt{.ipynb} files present
        \item \textit{Fix:} Include feature engineering scripts and a single pipeline entrypoint
    \end{itemize}
    
    \item \textbf{Environment not specified}
    \begin{itemize}
        \item \textit{Issue:} Parquet files require specific engine (pyarrow/fastparquet)
        \item \textit{Fix:} Add \texttt{requirements.txt} or \texttt{environment.yml}
    \end{itemize}
    
    \item \textbf{Incomplete temperature pipeline}
    \begin{itemize}
        \item \textit{Issue:} In one dataset variant, \texttt{tmean\_baseline\_sd} and \texttt{tmean\_z} are missing
        \item \textit{Fix:} Implement baseline computation and populate z-scores consistently
    \end{itemize}
    
    \item \textbf{Untraceable derived constructs}
    \begin{itemize}
        \item \textit{Examples:} \texttt{valor\_total}, \texttt{area\_total\_ha}, \texttt{num\_practices}, \texttt{riego\_share}
        \item \textit{Fix:} Add feature specification document or code comments with exact formulas
    \end{itemize}
\end{enumerate}
